# Sales data analysis project
Analyzed bike sales data and built an interactive dashboard using Microsoft Excel.
## Tools used:
-Excel
-Piovet tabels
-Piovet Charts
-Slicers
-Data cleaning
## Key Insights
1-middle aged customers are the most likely to purchase bikes
2-customers with higher income tend to buy more
3-male customers purchase slightly higher the females
4-Commute distance affects purchasing behavior
## Projecrs Features
1-Interactive dashboard
2-clear visualizations for decision making
3-filters by martial status, region, occupation, and education
